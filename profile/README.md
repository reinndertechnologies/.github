# Reinnder Technologies

**Reinnder Flock** is a poultry house monitoring kit in prototype: a sensor node on the roof ridge, a gateway that keeps every reading through an internet outage, and a water sensor that is planned. It watches beside a farm's own controllers and controls nothing.

It is a concept. Nothing is on sale, and no results from a working farm have been published yet.

## Open source

| Repository | What it is | Status |
|---|---|---|
| [flock-gateway](https://github.com/reinndertechnologies/flock-gateway) | The store-and-forward core of Flock: keeps readings in order through an outage and a restart, with simple local alerts. MIT licence. | Prototype, tested on a bench only |
